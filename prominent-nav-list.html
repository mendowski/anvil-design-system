Prominent nav list item

Prominent nav list item is a main navigation component for lists that need visual weight. It highlights key destinations in the app or website and gives people a clear, highly visible way to reach important pages and features.

Usage

Prominent styling

  • A background fill and border make each item stand out, which helps for important items or key actions.
  • Use it when the list needs more emphasis or is a key focus area, and when the page background is subdued rather than base.
  • It's easy to find, which makes it right for core sections and frequently used content, and helps guide people to important actions and information.

What only this item has

Other nav list items don't have these.

  1. Graphics: an icon in a color-filled circle, or a spot graphic (a spot illustration, or an avatar for profiles and images).
  2. Label or full-width alignment for the content.
  3. A Completed state, to mark a task or goal as done.

Accessibility

Using this component on a page still needs an annotated design review of the page-level design.

Headings

  • The label can be announced as any heading level or as body text, even when it looks like heading 4. Annotate the level you want; each platform has a prop for it.

Screen readers

  • People must be able to tab or swipe to each item, and hear all its visible text, plus its role if it's clickable.
  • The first item in a group is announced with "List, N items", then "<all visible text>, 1 of N". Later items: "<all visible text>, n of N".
  • Completed and postponed items need visible text that says their state, such as "Completed" or "In progress", so it isn't shown by the graphic alone.

In code

  • NavList renders a <ul>, so screen readers announce the list and its count. Pass label to name it.
  • With href an item is a link; with onClick it's a button. Disabled items get aria-disabled.

Code vs. Figma.
  • React has no prop for the label's heading level yet; the label renders as plain text.
  • Completed and postponed items don't add any text on their own. Say the state in the eyebrow or metadata, such as "Completed".
  • Nothing stops custom content from holding links or buttons. Keep it non-interactive.
