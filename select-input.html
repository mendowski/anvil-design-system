Select input

Select input lets people pick one answer from a list of set options. It usually sits in forms with other inputs. Choosing it opens a dropdown menu of options under the control.

Usage

When to use

  • There's a reasonable number of options, and people don't need to search or filter them.
  • Only one option can be chosen.
  • There isn't room to show every option on the page.

When not to use

  • There are many options, or searching would help. Use an advanced select.
  • People can pick more than one. Use an advanced select or checkbox selection cards.
  • Each option needs more than a short description. Use selection cards.

Product usage

  • Request a visit: choosing your location
  • Medical history: describing conditions
  • Chronic Condition Management: picking a time frame for health data, such as the past 14 days, 1 month or 3 months

Variants and options

Placement

Choosing a select input opens a menu of options. The menu floats over the page.

Interaction

iOS wheel picker

  • On iOS, when no option has a description, the native wheel picker opens instead of the dropdown menu. It fills the width of the screen at the bottom, above the home indicator, and the page scrolls so the select sits right above it.
  • People scroll to an option and tap Done. Clear returns an optional select to its placeholder.
  • When at least one option has a description, iOS uses the dropdown menu, since the wheel picker can't show descriptions.

Accessibility

Using select inputs on a page still needs an annotated design review of the page-level design.

Web

  • All visible text must be announced. Screen readers describe selects differently: VoiceOver says "popup button" when closed and "expanded" when open; NVDA says "combobox, collapsed", then "expanded, list" with the selected option and its position.
  • A view-only select isn't skipped in the tab order, so annotate its tab stop.
  • A disabled select is skipped in the tab order (don't annotate it), but screen readers can reach it with the arrow keys. VoiceOver says "dimmed", NVDA "unavailable".
  • Inline error icons don't need alt text.

Keyboard

KeyWhat it does
↓, ↑, Enter, SpaceOpens the menu on the selected option, or the first one.
Home, EndOpens the menu on the first or last option, or moves there when it's open.
↓, ↑ (menu open)Moves through the options.
Enter, Space, Alt + ↑Chooses the highlighted option and closes the menu.
Escape, TabCloses the menu without changing the answer.
A letterJumps to the next option that starts with it.

In code

  • The control is a combobox button that opens a listbox. Focus stays on the control while the highlighted option is shared with aria-activedescendant.
  • The label names the control, and the helper text and message are linked with aria-describedby. Errors set aria-invalid.

Code vs. React SDK.
  • The Pulse React SDK has two selects: Select, an older one built on the HTML select element, and DetailSelectInput, with a custom dropdown and option descriptions. Pulse.SelectInput here works like DetailSelectInput, which the SDK recommends for new work.
  • The iOS wheel picker is native to iOS, so it isn't part of the web component.
