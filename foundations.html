Design tokens

Design tokens are a shared language between designers and engineers. Designers use them as variables, styles and modes in Figma; engineers use them as variables in each platform's SDK, for color, type, spacing and more. The Pulse team maintains them to keep the product experience consistent.

Why use them

  • Brand consistency
  • Room to innovate while the UI stays cohesive
  • Themes for dark interfaces and private label instances (PLI)
  • Easier upkeep as tokens change for brand or accessibility
  • Smoother handoff to engineering

When to use them

  • Always. Designers and developers both use tokens throughout their work, to stay consistent and support themes.
  • Use them alongside Pulse components, which are built from the same tokens.

What's available

  • Background, text, icon, stroke (border) and brand colors
  • Typography
  • Padding, space and space between
  • Sizes for icons and graphics
  • Border radius
  • Effects

For developers

  • Tokens are available for web, iOS and Android, with different syntax on each.
  • In Figma's Dev Mode, hover a variable, click the three dots and open its details: the code syntax for each platform is at the bottom. Some typography, focus and elevation tokens don't show there; use the token Airtable instead.
  • iOS: color tokens use UIKit syntax by default. For SwiftUI, replace .color with .swiftUIColor.
  • On this site: tokens/tokens.json has every token, and tokens/anvil-tokens.css has them as CSS custom properties, with one block per theme.

Color

The Pulse 5 palette is closer to the brand, and tokens were cleaned up to avoid repeats. Color tokens are grouped by how you use them.

Background

  • background-surface is for forms, cards, modals and anything that needs to stand apart from background-base.
  • Status backgrounds have their own group: background-status-*.

Text

  • text-header-* is for title, h1 and h2; text-header-serif for the serif headings.
  • Body and status text have their own groups: text-body-* and text-status-*.

Icon and stroke

  • icon-base is the default icon color. Use icon-status-* only to communicate a state.
  • stroke-base is the default border. Status strokes come in base and subdued.

Brand

  • brand-interactive-* is for interactive elements.
  • brand-primary-* and brand-accent-* are for fills and graphics that represent the brand, such as pavers, branded bars and filled backgrounds, never for interactive elements.

Component tokens

  • Use illustration and data viz tokens only in illustration and data viz components.

Typography

Type is built for legibility. Each style has two scales, for desktop and handheld screens, and Pulse 5 switches between them with variables, using the same style name.

What changed in Pulse 5

  • Reckless Neue for title and heading 1.
  • Lexend Deca for heading 2 to 4, eyebrow, body, body-small, utility, data and button.
  • Effra only for italics.
  • The base size went from 18 to 16.
  • A new type ramp, with simpler names that use variables instead of Large and Small screen sizes.

Categories

  • Heading: structures pages. Heading 1 (page title), heading 2 (section), heading 3 (sub-section), heading 4 (item).
  • Body: paragraphs and longer copy.
  • Utility: labels and form elements.
  • Button: interactive elements and actions.
  • Data: numbers, such as stats and data displays.

Line height and size

  • Headlines: font size × 1.2.
  • Body text: font size × 1.618, the golden ratio.
  • The base size is 16px = 1rem: 10, 12, 14, 16, 18, 20, 22, 24, 26, 30 and 38px (0.625 to 2.375rem).

Spacing

Spacing runs on an 8px base, and token names are multiples of it: space-100 is 8px. Like radius, they use numbers so new steps can be added.
