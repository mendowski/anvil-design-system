Data visualization

Data viz

Charts for health data, rebuilt from the Pulse 5 Data Visualization Figma library: bar, line, floating column and radial charts, with tooltips, legends, goals and empty states. They are live React components, so hover, tap or use the arrow keys to explore, and switch the theme at the top to see them in every theme.

Colors

--data-viz-*

Data viz has its own color tokens: 12 dataset colors with base, hover and subdued values in every theme, a gray for missing data, and colors for axes, gridlines, goals and tooltips. Use datasets 2, 4, 1 and 8 in that order when a chart has several.

Bar chart

Anvil.BarChartTry it in the playground

Bar chart compares values across categories, such as steps per day or doses per week. Bars rise from the baseline, with an optional goal line or goal range. It comes from the Figma "Chart-bar" and "Bar-chart" components in Pulse 5: Data Visualization.

Guidelines and props

Anatomy

  • Title (optional): title at 18/24 semibold and subtitle at 14/20 in text-body-subdued.
  • Plot: bars in data-viz-data-data-2-base (berry) by default, with 4px top corners. Gridlines use data-viz-axis-gridline and the baseline data-viz-axis-baseline.
  • Axes: x labels under the baseline and y labels on the right, both 12px in data-viz-label-axis-label. Set yAxis="left" or "none" to move or hide the y labels. The active column's x label turns data-viz-label-axis-active and semibold.
  • Goal (optional): goal={6} draws a dashed data-viz-goal-line with a green "GOAL" pill on the right. goal={[5, 7]} draws a data-viz-goal-range band. Change the pill text with goalLabel, or move it with goalPosition="left".
  • Tooltip: hover, tap or arrow-key to a column. The bar turns its dataset's -hover color and a dark overlay tooltip shows the x-value and value. When there isn't room above, the tooltip moves beside the bar.
  • Legend: shown with more than one dataset.

Data

  • One dataset: data={[4.2, 6.8, 5.1]} with categories={["Mon", "Tue", "Wed"]}. A second label row goes in categories={[{ label: "1", sublabel: "A" }]}.
  • Up to four datasets: series={[{ label: "Taken", values: [...] }, { label: "Missed", values: [...] }]}. They sit side by side in each column, in datasets 2, 4, 1 and 8 (berry, green, aqua, yellow) unless you set color.
  • unit follows each value in the tooltip, such as "k steps".
  • The y-axis rounds up to a clean number above the data and goal. Set yMax and yStep to fix it.
  • 12 columns or more use a 4px gap; fewer use 8px.

Empty states

With no data, or with empty, a ghost bar chart shows with a message: "No data yet" (status: "zero") or "Data unavailable" (status: "unavailable"). Add a description. See ChartEmpty.

Accessibility

  • It renders as a <figure> named by its title, with a visually hidden table of every value for screen readers.
  • The plot is one tab stop. Arrow keys, Home and End move between columns, Escape clears, and each change is announced.
  • Don't rely on color alone: label datasets in the legend and keep the unit in the tooltip.

Line chart

Anvil.LineChartTry it in the playground

Line chart shows trends and change over time for one to four datasets, such as weight or blood glucose by day. It comes from the Figma "Line-chart" component in Pulse 5: Data Visualization.

Guidelines and props

Anatomy

  • Title (optional) at 18/24 semibold, with an optional subtitle.
  • Summary or inline tooltip: a track between the title and the plot. Until someone explores the chart it shows summary, such as { value: "126", unit: "mg/dL", label: "Average" } (also a compound value, or a range with range: true). While exploring, the light inline tooltip (data-viz-tooltip-background-secondary) slides along the track to the active point with the x-value, a dashed divider and each value.
  • Plot: horizontal and vertical gridlines, the baseline, and y labels on the right. A thin guide line marks the active x position.
  • Lines: 1.5px lines in datasets 2, 4, 1 and 8 (berry, green, aqua, yellow). Each dataset has its own node shape, circle, square, triangle and inverted triangle, so lines can be told apart without color. Active nodes are hollow, with a 2px ring in the dataset's -hover color.
  • Goal (optional): a dashed goal line or a goal range band, as in BarChart.
  • Legend: shown with more than one line or a goal.

Options

  • curve="curved" draws smooth curves; the default is straight segments.
  • nodes={false} hides the data points.
  • tooltip="overlay" uses the dark overlay tooltip over the plot instead of the inline one; tooltip={false} turns exploring off.
  • null values leave a gap in a line.

Accessibility

  • A <figure> named by its title, with a hidden data table.
  • The plot is one tab stop. Arrow keys move between x positions and the values are announced.
  • With several lines, the node shapes and legend carry meaning beyond color.

Floating columns

Anvil.FloatingColumnsTry it in the playground

Floating columns show a range for each category, such as a day's lowest and highest heart rate. Each column floats between its low and high value instead of rising from the baseline. It comes from the Figma "Floating-columns" component in Pulse 5: Data Visualization.

Guidelines and props

Anatomy

  • Columns in data-viz-data-data-2-base by default (set color for another dataset), with rounded ends.
  • Up to 12 columns fill their slot. More than 12 become 6px pills, as in the Figma 14- and 24-column versions, and every other x label is dropped past 16.
  • The axes, gridlines, goal and empty states work as in BarChart.
  • The tooltip shows the range: "64 bpm – 134 bpm".

Data

data={[{ x: "Mon", low: 60, high: 110 }, …]} with an optional unit.

Segmented columns

For data that comes in pieces, such as sleep, give each column segments instead of low and high: { x: "Sun", segments: [[2.4, 3.5], [3.7, 3.95], [4.25, 6]] }.

  • Every column gets a light track in data-viz-data-data-null-subdued for the window being measured (track, such as [2, 7]), so days without data still show as empty tracks.
  • Segments are data-viz-data-data-1-base (aqua) by default, with 4px corners. Short segments, such as a few minutes awake, stay at least 4px tall so they don't disappear.
  • The y-axis can show hours (formatY: t => t + " hr") or clock times (formatY that turns hours into "4 AM").
  • The tooltip is inline by default, like the line chart: the date (tooltipLabels), the total and a note such as "In bed". valueFormat="duration" writes hours as "3 hrs 45 min". Until someone explores the chart, summary shows there, such as "4 hours 25 minutes, Average time in bed". tooltip="overlay" uses the dark tooltip instead.
  • Vertical gridlines are on, and a guide line marks the active day.

Accessibility

Same as BarChart: a named <figure>, a hidden table with Low and High columns, and arrow-key exploring that reads "Mon: 60 to 110 bpm".

Radial chart

Anvil.RadialChartTry it in the playground

Radial chart is a donut that shows a part of a whole, such as 7 of 10 doses logged. It comes from the Figma "Chart-radial" component in Pulse 5: Data Visualization.

Guidelines and props

Anatomy

  • Track: a full ring in data-viz-axis-radial.
  • Progress: an arc from 12 o'clock, clockwise, in data-viz-data-data-2-base by default, with round ends edged in data-viz-stroke-radial so the end stands out from the track. At 100% it's a full ring.
  • Value: in the middle, the value at 18/24 bold in the dataset's data-text color (datasets 1–3; others use their base color) and the unit at 14/20 in text-body-subdued. Add a second line with value2 and unit2.
  • Size: 140px by default; the ring is 10% of the diameter. Set size and thickness.

Data

percent={70}, or value and max. display overrides the middle text.

Accessibility

It renders as role="img" with a name such as "Doses this week: 7 of 10 (70%)". Pass title or ariaLabel for context.

Tooltips

Anvil.ChartTooltip

Chart tooltips show exact values for the point being explored. The charts render them for you; use ChartTooltip directly for custom charts. From the Figma "Chart-overlay-tooltip" and "Chart-inline-tooltip" ("Chart-tooltip" is deprecated).

Guidelines and props

Variants

  • Overlay (default): data-viz-tooltip-background-primary (dark) with white text, 4px corners and a 16×8 beak. beak sets the side (top, right, bottom, left) and beakAlign the position (center, leading, trailing). BarChart and FloatingColumns use it.
  • Inline (variant="inline"): data-viz-tooltip-background-secondary (light) with the x-value, a dashed divider in data-viz-tooltip-stroke, and the values. LineChart puts it on a track between the title and plot.

Values

  • Single: values={[{ value: "NN", unit: "unit" }]}.
  • Compound: two values side by side.
  • Range: two values with range, joined by a dash.
  • Multiple datasets: up to four values with labels. Each gets the dataset's hollow data point (circle, square, triangle, inverted triangle).
  • Values are 14/20 semibold and units 12/12. supplemental adds a line of extra text.

ChartSummary

ChartSummary is the resting state of the inline track: the value at 18/24 bold, the unit at 14/20 and a 12px label, all in text-body-subdued. Use it for a total, average or range.

Legend

Anvil.ChartLegend

Chart legend names the datasets in a chart. The charts add it when there's more than one dataset or a goal; use it directly for custom charts. From the Figma "Chart-legend" and "Chart-legend-item".

Guidelines and props

Anatomy

  • Items wrap in a row with 16px between them. Labels are 12/12 in data-viz-label-legend, 8px from the icon.
  • Data: an 8px data point in the dataset's base color and shape.
  • Goal line: a short dashed data-viz-goal-line.
  • Goal range: an 8px square of data-viz-goal-range between dashed lines.
  • Add the goal item with goal="line" or goal="range".

Dataset colors

Data viz has 12 dataset colors, data-viz-data-data-1 to -12, each with base, hover and subdued values in every theme, plus data-viz-data-data-null gray for missing data. Datasets 1–3 also have a -data-text color for values set in text.

Use them in this order so charts look alike across the product:

  1. Data 2, berry, circle
  2. Data 4, green, square
  3. Data 1, aqua, triangle
  4. Data 8, yellow, inverted triangle

Check contrast: graphics need 3:1 against the background and text 4.5:1. Pair color with shape and labels.

Empty states

Anvil.ChartEmpty

Chart empty states replace a chart that has nothing to show: a gray ghost chart with a message card over it. From the Figma "Chart-empty-message" and the ghost charts on the Empty states page.

Guidelines and props

Statuses

  • Zero data (status="zero", default): "No data yet" with the info icon. Use it before someone has logged anything.
  • Data unavailable (status="unavailable"): "Data unavailable" with the cloud-disconnected icon. Use it when data couldn't load.
  • Add a description that says what to do next, such as "Log your first reading to see your trend."

Anatomy

  • Ghost chart (chart): bar, line or radial, drawn in data-viz-data-data-null-subdued.
  • Message: up to 300px wide on background-base with a stroke-base border, 12px corners and the elevation shadow. The title is 14/20 semibold and the description 14/20 in text-body-subdued.

BarChart, LineChart and FloatingColumns show this automatically when they have no data, or when you pass empty={{ status, title, description }}.

Accessibility

The message is a role="status" region, so it's read when it appears. The ghost chart is hidden from screen readers.
