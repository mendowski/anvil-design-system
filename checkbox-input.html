Checkbox input

A checkbox lets people pick any number of options from a set, from none to all. Each checkbox in a group is independent: checking one doesn't uncheck the others. Checkbox input is built on the standalone Checkbox.

Usage

Use checkboxes when

  • People choose one or more options from a list of related items.
  • An explicit action is needed to apply settings or agree to terms.

Always tell people

  • Whether a checkbox is required
  • Whether they can pick more than one
  • Whether a group is required

Pair with a button

  • Add a button that applies the choices, labeled for the context.
  • For a setting or preference: "Save setting" or "Save".
  • In a flow: "Next" or "Continue".

Product usage

  • Requesting service
  • Medical history (self or dependent): existing and family conditions
  • Account settings

Used in

  • Checkbox input
  • Table: selecting rows or columns in a complex table

Accessibility

Using checkboxes on a page still needs an annotated design review of the page-level design.

KeyWhat it does
TabMoves focus to the input, and can move to the next input in a group.
Space, EnterChecks or unchecks the checkbox.
Arrow keysMove focus to the next input in a group.

Screen readers

  • Every visible text must be announced.
  • VoiceOver says "checked" or "unchecked". NVDA and JAWS say "checked" or "not checked".

Links in labels

  • On Android, a link in a label is always a button.
  • On iOS, it's a link if it opens an external website, and a button otherwise.

In code

  • CheckboxGroup renders a <fieldset> with the label as its <legend>, and links the helper text and message to the group.
  • Each checkbox is a native <input type="checkbox"> inside its label, so the whole block is clickable.

Build tips

Groups

  • Checkbox inputs usually sit in a stacked group. Show the label and helper text only on the first input.
  • In the error state, show the inline message only on the last input, and the error on every checkbox.
  • In code, CheckboxGroup does both for you: pass label, helper, status="error" and message to the group.

Labels with links

  • In Figma, add link and color styles by hand in the "with links" variant, on web, iOS and Android.
  • In code, pass the label as children with real links inside.

Code vs. Figma.
  • The exclusive-selection behavior ("None of these" disabling the others) is up to the page. The example above wires it up with state.
  • With links in the label, clicking the label's plain text still toggles the checkbox in code, because the whole block is a <label>. Figma limits the target to the checkbox and the links.
  • FlowUI's CheckboxGroup doesn't yet allow several text links in one label.
